# Projeto TP2 de TI
Projeto realizado no âmbito da disciplina de TI com o objetivo de analisar e criar um codec para ficheiros de imagens do tipo TIFF (Tag Image File Format).<br>
Fazes do projeto:
* [1. Fase de investigação](#fase-de-investigação)
  * [Introdução](#fase-de-investigação)
* [2. Fase de implementação](#fase-de-implementação)

## Fase de investigação
Pretende-se a realização de uma análise estatística de ficheiros de imagens do tipo TIFF. Para começar espera-se realizar várias análises dos dados de teste. Isto é:
 - Análise da entropia do ficheiro
 - Análise de entropia conjunta das imagens
 - Análise de possíveis modelos matemáticos nas imagens
